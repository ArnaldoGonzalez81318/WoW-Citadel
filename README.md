# WoW Citadel

![image]()

## Table of contents

### Description

WoW Citadel is a web application that allows you to see the characters of the game World of Warcraft, their statistics, equipment, and more.

[🚀 See the demo here.](https://wowcitadel.netlify.app)

### Front-end

* React js
* nextui

### Installig

```
yarn install
```

### Running app

```
yarn dev
```
